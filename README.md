# tempo

Temporizador de intervalos para entrenar: Tabata, EMOM, AMRAP y modo libre, con trabajo, descanso, series, ciclos y preparación configurables.

Es un único archivo, `index.html`, sin dependencias ni compilación.

## Funciones

- Modos rápidos Tabata (20/10 × 8), EMOM (1 min × 10) y AMRAP (12 min), además de un modo libre.
- Rutinas guardadas con nombre, que se almacenan en el navegador del dispositivo.
- Avisos con pitidos, voz o silencio: cuenta atrás 3-2-1 al final de cada fase y un tono distinto para trabajo y para descanso.
- Modo entreno: mientras corre se muestra solo el reloj, también en horizontal.
- La pantalla se mantiene encendida mientras el temporizador está en marcha.

## Instalar en el iPhone

1. Publica el repo con GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
2. Abre la URL de Pages en Safari.
3. Pulsa Compartir → **Añadir a pantalla de inicio**.

Se abre a pantalla completa con icono propio. El sonido funciona con el interruptor de silencio activado desde iOS 17 y la pantalla se mantiene encendida desde iOS 16.4.
